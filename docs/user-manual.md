# 用户使用手册

XConnect 是一个用户友好的多节点网络加速客户端，基于 Xray-core 构建，提供流畅、可靠的网络连接体验。

## 本地连接与额度通知（全部平台）

Windows、macOS、Linux、iOS 和 Android 使用相同的导入与应用内通知逻辑。

- 手动输入或从剪贴板、二维码导入的连接保存到本设备应用数据目录。重启、退出登录、切换账号、服务端额度耗尽或账号同步清理不会删除这些手动连接。
- 每次导入使用独立的配置文件；同名连接自动添加数字后缀，保留原连接。历史上已经被覆盖的配置需要重新导入。
- 长期保存以应用数据仍在为前提；主动删除、清除应用数据或卸载可能移除配置，请自行保管原始连接资料。
- 顶部铃铛打开通知中心。未读额度提醒显示圆点，打开后标记已读；当前额度状态仍保留在提示栏中，直到服务端状态恢复。
- 套餐内剩余额度严格低于 10% 时提示；恰好 10% 不触发。无限额度和临时无限覆盖不触发低额度提醒。字段缺失时不猜测额度。
- 套餐内额度为零与服务端拒绝同步分别提示。按量付费余额、授权和实际连接可用性仍由服务端决定；只有明确的额度错误码才显示“额度耗尽导致同步暂停”。其他权限和网络故障保留各自错误。
- “设置 → 通知”可关闭低额度提醒；服务端额度暂停状态仍显示。可在通知中心点击“检查额度并重试同步”，也会在应用运行且已登录期间随自动同步约每 10 分钟检查。应用关闭或被系统挂起时不承诺后台刷新。
- 本版本提供应用内通知，不申请系统通知权限、不发送后台推送。通知内容与已读状态按账号保存；退出后隐藏，切换账号不显示上一账号的通知。

服务端兼容性：客户端读取 `/api/account/usage/summary` 的 `includedQuotaBytes`、`remainingIncludedQuota`、`temporaryUnlimited`、`currentPlan.unlimited` 与 `networkAccessState/networkAccessReason`；兼容旧版 `billingProfile` 的总额度字段。额度接口不可用时继续正常节点同步，并保留上次已知通知；节点接口返回明确 `quota_exhausted` 等额度错误时仍可提示暂停。恢复额度或下个额度周期后可重试，客户端不会绕过服务端额度规则。

## 系统 VPN 流量方式

在 **设置 → 路由** 选择 **智能路由** 或 **全局代理**。这项设置适用于 macOS、iOS、Android、Windows 和 Linux 的标准系统 VPN 配置，下次从 XConnect 连接时生效。

- **智能路由**。局域网和命中中国大陆域名规则（包括 `.cn` 顶级域及国内常见互联网服务域名）的流量直连，其余公网业务流量经 VPN 节点转发。这是默认模式。
- **全局代理**。公网业务流量统一经 VPN 节点转发，局域网与私有 IP 仍可直连。DNS、HTTP/3 和必要系统连通性探测按现有规则处理。IPv4 和 IPv6 的覆盖范围由平台的 VPN 路由决定。

从 Apple 系统设置连接时，系统使用最近保存的 VPN 配置。全局代理需要使用启用 TLS 证书校验的标准节点。遇到不兼容的节点配置时，可以切回智能路由，或换用标准 TLS 配置。本地 HTTP 和 SOCKS 代理使用原有路由。

## 初始化与配置

本手册将指导你如何在 macOS 上完成 XConnect 的初始化和默认节点生成操作。

### 安装并初始化

1. 下载并解压安装包。
2. 双击 `.dmg` 文件，首次运行时可能需要拖入 `Applications` 文件夹。
4. 系统提示“来源不明应用”时，可右键点击 → 选择“打开”。
5. 授权访问：系统可能会提示授予“网络权限”、“全盘访问”等，请允许。

## 步骤 1：点击右上角 🔒 图标解锁

首次使用前需要进行权限验证以解锁高级功能。

![步骤1](images/unlock-button.png)

点击界面右上角的 🔒 图标，输入系统密码进行解锁。

## 步骤 2：初始化 Xray

解锁成功后，点击左侧“设置中心”中的 `初始化 Xray` 按钮：

![步骤2](images/init-xray.png)

系统会弹出 macOS 原生权限窗口，请再次输入密码确认操作。

## 步骤 3：生成默认节点

初始化完成后，点击 `生成默认节点`，系统将自动创建配置文件、Plist 启动项与节点数据。

![步骤3](images/log-result.png)

日志区域会显示详细的操作记录，包括配置保存路径、文件生成成功等信息。

---

## 步骤 4：添加自定义加速节点配置

点击底部导航栏中的 `Subscriptions` 标签页，在添加页面中填写你自己的节点信息，例如：

- 节点名（如 `Global-Node`）
- 服务器域名（如 `global-node.onwalk.net`）
- 端口号（如 `1443`）
- UUID（如 `18dxxxxx-xxxx-xxxx-xxxx-e7fxxxxx9b2`）

点击 `生成配置并保存` 按钮，系统将自动写入对应配置并可用于同步服务。

![步骤4](images/custom-node-form.png)

## 步骤 5：同步配置文件

### 业务域名的加密 DNS 解析

默认配置已开启 `DNS over HTTPS` 和“隧道 DNS 走代理”
（iOS 自动使用此策略），选择有效节点连接即可使用。业务域名的 IPv4 A 记录查询
会通过隧道使用 Cloudflare 与 Google DoH；节点域名、内网名称和已有直连
域名例外保留原有策略，其他 DNS 记录类型也继续原有转发。修改 DNS 设置后
需要重新连接隧道。

“基础 DNS”仍填写 DNS 服务器 IP 地址，用于系统 DNS、例外域名和非 A 记录。
两个 DoH 上游各等待最多 1.5 秒；两者均失败时，自动经同一隧道查询主基础 DNS
（默认 `1.1.1.1`）。基础 DNS 在出口节点到解析器之间使用明文协议，
DoH 则为业务 A 查询加密这一段传输。关闭 DoH 后重连即可恢复原有
隧道 DNS 路径。如果隧道或所有上游均不可达，查询仍可能超时。

在主界面中点击左侧的 `同步配置` 按钮，将当前选中的节点配置写入系统服务中。

![步骤5](images/sync-config.png)

此操作会根据选中的节点保存并应用配置到本地服务。


### 配置浏览器加速插件

使用 ZeroOmega 连接 Xray 节点。本指南假设你已经在本地或远程服务器上成功部署了 Xray-core，可在浏览器中通过 ZeroOmega 实现节点切换。

1. 安装 ZeroOmega 插件（https://github.com/zero-peak/ZeroOmega）。  
   ZeroOmega 支持 Chrome Web Store、Microsoft Edge Addons、Firefox Addon，兼容 SwitchyOmega，基于 Manifest V3。
2. 在 ZeroOmega 创建 Xray 节点配置：
   - 情景模式名称：例如 Xray-SOCKS5
   - 服务器类型：SOCKS5
   - 服务器地址：127.0.0.1
   - 端口：1080
   - 保存配置。
3. （可选）设置自动切换规则：
   - 创建新的「自动切换模式」，可导入 GFWList、PAC 或自定义规则。
   - 规则示例：
     - *.google.com  --> 使用 Xray-SOCKS5
     - *.youtube.com --> 使用 Xray-SOCKS5
   - 默认模式设置为「直连」，其余符合规则的域名通过 Xray 加速服务访问。
4. 效果验证：
   - 访问 https://www.google.com/ 等站点，确认是否已通过加速服务。
   - 也可通过浏览器访问 ip.sb 查询外网地址。

### 启动加速服务

1. 返回应用主界面，选择节点（如 🇺🇸 US-Node）。
2. 点击启动/停止按钮控制服务。
3. 可在“设置”页面查看实时日志信息。

### 匿名统计

在“设置中心”中，点击“查看收集内容”可查看收集到的 JSON 数据，按钮右侧的开关用于开启或关闭此功能。

##  常见问题&故障排查

- 若初始化按钮处于灰色，请先完成解锁。
- 若权限认证失败，请检查系统用户是否具备管理员权限。
- 日志中如显示路径无权限写入，请尝试以管理员身份运行程序。
- 无法联网？请确认端口是否正确配置为 `1080`，且节点状态为“运行”。

## 自托管连接器登录异常

后台同步遇到权限或节点接口 401 时，不自动退出登录，也不删除已保存的登录凭据、
账号信息或连接配置。只有用户主动退出或明确切换连接器才清理登录状态。
服务端拒绝授权时暂停托管连接，已保存的配置仍保留；独立导入的连接不受影响。
服务恢复后可点击同步或等待自动同步；凭据确实失效时需重新认证，客户端不会绕过
服务端认证或延长已失效会话的寿命。

### 连接器认证失败后恢复同步

点击“立即同步”会在当前页面使用已有会话重新同步，不跳转登录表单。
客户端遇到 401 时会尝试已有的独立会话 Cookie、服务端曾签发的刷新令牌，
并对仍被拒绝的读取最多重试一次。恢复成功后继续同步节点。
若服务端已撤销所有凭据且未签发刷新令牌，则本次同步仍会失败，保留登录
和节点文件，但不会绕过服务端授权。登录及 MFA 请求在 20 秒后超时。
原生停止隧道请求最多等待 10 秒；超时不代表系统隧道已停止。

## 应用隐私检查

在 **设置 → 系统设置 → 应用隐私检查** 查看系统时区、首选语言、区域和可读取的 DNS
配置。点击 **检查应用出口** 后，XConnect 才会访问 IPinfo，显示这次连接的公网 IP
和估计位置，并提示系统区域或时区标识与出口是否不同。差异可能来自 VPN、旅行或个人偏好。
DNS 列表是系统配置，不能用来判断浏览器的实际解析出口或是否有泄漏。部分平台可能无法读取 DNS。

桌面版可点击 **检测默认浏览器**。短时开放的本机页面显示当前浏览器的时区、语言、区域、
User-Agent、屏幕尺寸、字体样本以及 Canvas、WebGL、音频、WebRTC 和 Cookie 的可见状态。
在该页面点击 **检查浏览器出口** 可通过 IPinfo 单独查询浏览器出口。WebRTC 和音频显示的是
接口可用性。Cookie 显示浏览器报告的开关状态。浏览器页不会检查 DNS 或 WebRTC 泄漏。

点击 **复制系统检查提示词** 可复制系统摘要。在浏览器页可预览并复制合并提示词。
提示词省略实际出口 IP、DNS 地址、完整 User-Agent 和具体字体名称，仍包含时区、语言、
估计位置等环境信息，分享前可先核对。卡片只做辅助检测并提供建议。
